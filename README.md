# YOWLMAFFIA

YOWLMAFFIA is een Windows desktop app voor de crew. Iedereen installeert gewoon de app en werkt daarna online samen.

## Voor teamleden

1. Installeer `YOWLMAFFIA.exe`.
2. Open de app.
3. Log in.
4. Alles wat je doet komt online beschikbaar voor het team.
5. Updates verschijnen in de app en kan je daar meteen downloaden.

Geen Node.js nodig. Geen aparte setup nodig. Alleen de app installeren.

## Wat zit erin

- Login zonder registratie
- Dashboard met songs
- Realtime editor
- Chat en privéberichten
- Player voor audio
- Profielfoto, status en thema
- .yowl import en export
- Updates vanuit de app
